# RARI Boutique System 👗💎
A full-stack retail management solution integrating Python and a MySQL relational database.

### 🚀 Key Features
* **Inventory Management:** CRUD operations for Dresses, Jewelry, and Employee databases.
* **Analytics:** Real-time stock visualization using **Matplotlib**.
* **UI/UX:** Image rendering with **Pillow (PIL)** and formatted data grids via **Tabulate**.
* **Full E-commerce Flow:** Modules for user authentication, shopping carts, and simulated payment processing.

### 🛠️ Tech Stack
* **Language:** Python
* **Database:** MySQL
* **Libraries:** Matplotlib, PIL, Tabulate, MySQL-Connector
